Engine: Wolfram Language 15.0.1 (remote kernel; the local engine was not activated, so `b2_03w_reduce.wl` — the same
computation as one batch — could not be run locally). Input matrices: `b2_02_matrices.wl` ($b_s=1$; generated by

$\xi_1=1$. Domain: $b>0$, $\tau_R,\tau_\ell\ge0$, $R\ge0$; $\varepsilon,\varepsilon_0,\tau_n$ real. The remote kernel enforces a
wall-clock limit of about one minute per call; systems that exceeded it were decomposed as described (the decomposition is part of
the proofs in `proofs/B-revision.md`, §3.3–§4).

Common code (per call):
```
dom = b > 0 && tR >= 0 && tl >= 0 && R >= 0;
lev[M0_, k_] := Module[{M = M0 /. xi -> 1, n, ms, vars},
  n = Length[First[M]];

  vars = Select[{b, tR, tl, R, eps, epsz, tn, to}, ! FreeQ[M, #] &];
  Reduce[And @@ Thread[ms == 0] && dom, vars, Reals]];      (* k = 0: rank < n;  k = 1: rank <= n-2 *)
```
