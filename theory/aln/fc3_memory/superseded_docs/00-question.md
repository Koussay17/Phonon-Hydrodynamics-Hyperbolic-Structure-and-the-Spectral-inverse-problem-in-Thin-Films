# 00 — Question: is the closure memory time determined in the fc3-parametrised rate class?

**Date opened:** 5 October 2026. Paper 1 (conserving phonon closures, memory moment).

## Context
The memory-gap campaign (`D:\ResearchLab\orchestration\campaigns\20261004-memory-gap`, thesis copy
`theory/aln/memory_gap`) showed that, for ARBITRARY non-negative event rates on the fixed AlN
three-phonon event set (5x5x3 mesh, Gaussian sigma = 0.1 THz, 300 K), the 300 K mode lifetimes and the
DC conductivity tensor leave the memory time

    tau_mem = b^T (C^+)^2 b / b^T C^+ b,   C = sum_alpha g_alpha z_alpha z_alpha^T  (entropy coordinates)

undetermined by factors 10^2 - 10^5 above the reference (34.25 ps basal, 27.45 ps c axis), while a
per-event amplitude prior g >= g_ref/F caps it at F / lambda_min(C_ref|H) = 81.50 F ps.
That campaign ended by naming the physically decisive open computation: the rate class generated by
actual anharmonic force constants.

## Question
Rates in the fc3 class are g_alpha(T) = W_alpha(T) |Phi_alpha(fc3)|^2, with W_alpha the exact kinematic,
Bose and energy-delta weight (Gaussian sigma = 0.1 THz, same event set as the memory-gap reference) and
|Phi_alpha|^2 the three-phonon matrix element computed from a third-order force-constant tensor fc3.
fc3 is the unknown, within physically plausible uncertainty (space group, permutation symmetry and
acoustic sum rule respected).

1. Does the fc3 route reproduce the memory-gap reference (kappa_xx 214.30, kappa_zz 201.97 W/(m K);
   tau_mem 34.25 / 27.45 ps)?
2. How much do kappa, tau_mem, tau_CS = K/|b|^2 and lambda_min(C|H) move under physically motivated fc3
   variants: (a) phase convention make_r0_average True/False; (b) real-space cutoff truncation of fc3,
   re-symmetrised; (c) random symmetry-preserving perturbations of relative size 1, 5, 10, 20 %?
3. Constrained (fc3-class analogue of the memory gap): among symmetric fc3 perturbations that keep all
   300 K lifetimes within 5-10 % per mode and kappa within 1 %, what range of tau_mem is attainable?
   Compare with the free-rate class (factors 10^2 - 10^5) and with the factor-F ceiling.
4. Mesh sensitivity of the key numbers (7x7x5).
5. Independent second route for at least one tau_mem.

**Decision criterion for paper 1:** is tau_mem pinned to within a factor ~1.x by the amplitude
structure (fc3 class), or does a large gap persist?
