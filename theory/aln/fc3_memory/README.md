# fc3 memory — the closure memory time in the force-constant-generated rate class (paper 1), October 2026

Question: when the three-phonon rates are generated by symmetric third-order force constants (fc3) and fc3 is
allowed to vary within first-principles-level precision, do static transport data (mode lifetimes, kappa) determine
the memory time τ_mem = N/K of the conserving closure of AlN at 300 K? Start with `13-final-report.md` (third
version); the two earlier versions are in `superseded_docs/` and the reasons for each revision in
`09-failed-approaches.md` (items 14–19). Reviews: `review/counterexample-review.md`, `review/numerical-audit.md`,
`review/peer-review.md`.

Result (status labels as in the report):
- τ_mem is an infrared quantity: carried by the Γ-adjacent acoustic modes, not converged on any mesh computed
  (event operator 34.3 → 73.6 ps from 5×5×3 to 12×12×8; RTA 60.2 → 135.4 ps from 9×9×5 to the benchmark grid
  31×31×17 while κ changes by 11 %). The part above 3 THz is mesh-converged (31.7 / 27.8 ps, RTA). Existence of a
  bulk limit: unresolved; infrared divergence plausible.
- On each discretised operator the static data leave τ_mem undetermined by large factors (5×5×3 calibrated class
  [0.70, 2.35]; two-mesh constraints still allow 3.05 on 7×7×5). Calibrated-class witnesses are mesh-specific; a
  per-cluster c-axis effect (slower long-wavelength TA modes) persists through 9×9×6 (1.37 → 1.35 → 1.52). Every
  witness violates the data on a mesh not used in its construction.
- Identifiability of bulk τ_mem from static data: unresolved, possibly ill-posed. Paper 1 should use a regularised
  memory time (frequency cutoff or film thickness) rather than a bulk first-principles τ_mem.
- Film-regularised memory time (E33/E37, three data meshes, held-out 12×12×8 check; inner bounds, multistart E39 and numerical
  audit pending): admissible film τ_z ratio in the per-cluster ε = 0.1 class [0.973, 1.028] at 30 nm, [0.963, 1.038] at 100 nm,
  [0.949, 1.054] at 300 nm; calibrated classes at 100 nm up to [0.921, 1.080]. The film quantity is mesh-stable where the bulk
  one is not.
- Second functional (E38, Block C): PBE supercells complete (467/467); PBEsol in progress.
