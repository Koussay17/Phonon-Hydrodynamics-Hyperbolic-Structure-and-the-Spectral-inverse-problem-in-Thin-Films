## Context
The memory-gap campaign (`20261004-memory-gap`, thesis copy `theory/aln/memory_gap`) showed that for ARBITRARY
non-negative event rates on the fixed AlN three-phonon event set (5x5x3 mesh, Gaussian sigma = 0.1 THz, 300 K)
the 300 K lifetimes and the DC conductivity tensor leave the memory time

    tau_mem = b^T (C^+)^2 b / b^T C^+ b,   C = sum_alpha g_alpha z_alpha z_alpha^T  (entropy coordinates)

undetermined by factors 10^2 - 10^5 above the reference (34.25 ps basal, 27.45 ps c axis), while a per-event
amplitude prior g >= g_ref/F caps it at F / lambda_min(C_ref|H) = 81.50 F ps. It named the decisive computation:
the rate class generated by actual anharmonic force constants.

## Question
Rates in the fc3 class: g_alpha(T) = W_alpha(T) |Phi_alpha(fc3)|^2, W_alpha the exact kinematic, Bose and
energy-delta weight (same event set and smearing as the memory-gap reference), |Phi_alpha|^2 the three-phonon
matrix element of a third-order force-constant tensor fc3 (unknown, within physically plausible uncertainty,
respecting space group, index permutation symmetry and the acoustic sum rule).
1. Does the fc3 route reproduce the memory-gap reference (kappa_xx 214.30, kappa_zz 201.97 W/(m K);
   tau_mem 34.25 / 27.45 ps)?
2. How much do kappa, tau_mem, tau_CS = K/|b|^2 and lambda_min(C|H) move under (a) make_r0_average True/False,
   (b) real-space truncation of fc3 (re-symmetrised), (c) random symmetric perturbations of 1, 5, 10, 20 %?
3. Among symmetric fc3 perturbations keeping all 300 K lifetimes within 5 - 10 % and kappa within 1 %, what range of
   tau_mem is attainable (fc3-class analogue of the memory gap)? Compare with the free-rate class and the factor-F
   ceiling.
4. Mesh sensitivity (7x7x5).
5. Independent second route for at least one tau_mem.
**Decision criterion for paper 1:** is tau_mem pinned to within a factor ~1.x by the amplitude structure, or does a
large gap persist?
