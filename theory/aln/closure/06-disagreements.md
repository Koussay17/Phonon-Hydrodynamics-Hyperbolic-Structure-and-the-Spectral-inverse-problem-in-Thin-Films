# Disagreements and resolutions

| Proposition | Competing statements | Resolution |
|---|---|---|
| Does conserving projection reproduce RTA? | It changes the diagonal; it can retain the DC current response. | Both true: audited pseudoinverse identity distinguishes matrix entries from an observable. |
| Is memory unbounded at fixed DC? | Yes in a broad PSD family; no in one fixed finite event cone. | Different admissible sets. The Cauchy-Binet proof resolves the apparent conflict. No material inference by vote. |
| Does a positive-rate mesh certify continuum memory? | Stable sums; unresolved infrared tail. | Finite-sum arithmetic verified; continuum moment remains unknown. |
| Does r(q)~a q^alpha imply a density asymptotic? | First pass used a pointwise change of variables. | Explicit monotone oscillatory-derivative counterexample; add derivative control or prove a cumulative-measure result separately. |
| Does a full scalar export provide even dynamics? | Array shape suggests completeness; primary equations use oddness. | Inspected Python/C formula is conductivity-equivalent on odd populations. Physical even action is a separate requirement. |
| Can a small Schur error certify response? | Absolute error can vanish while relative response error persists. | Resolvent conditioning and coordinate inertia explain it; no contradiction to the stated absolute bound. |
