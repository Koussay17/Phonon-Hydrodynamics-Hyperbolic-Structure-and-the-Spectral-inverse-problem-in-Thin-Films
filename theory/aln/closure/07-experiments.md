# Reproducible experiments

Repository-relative commands are in README.md. Included experiment families:

1. constructive_collision: exact graphs and Walsh construction, dense/spectral/high precision, retained failures.
2. infrared_audit: independent capacities, inverse-moment concentration, radial exact model, angular refinement and grazing floor.
3. pi_response_bounds: 100 SPD matrices x 40 real-Laplace shifts; direct solves check Jensen bounds.
4. red_proof_checks: exact symbolic identities and a density-asymptotic counterexample.
5. red_numerical_audit: independent rational and precision-refined checks, separate 75-digit physical-data sums, both endpoint artifacts.
6. second_generation_schur: 600 direct/eliminated systems, absolute bounds, coordinate and pole tests.
7. scripts/analyse_aln_response.py: corrected bulk RTA response and both error metrics with provenance.

No physical mesh refinement, N/U trajectory, full AlN collision solve or laboratory experiment has been run. A planned red_counterexample_checks script was never saved/run; its report contains a correction. Do not cite that nonexistent run.
