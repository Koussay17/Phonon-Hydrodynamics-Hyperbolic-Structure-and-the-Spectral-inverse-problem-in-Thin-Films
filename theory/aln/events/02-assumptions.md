# Assumptions
Finite equal-weight full-grid modes, positive energies and temperature,
stipulated reversible Bose population flux, nonnegative coefficients,
exact resonance for the mathematical identity, explicit unique-event counting.
Reciprocal symmetry additionally requires a valid partner map and equal
partner coefficients. The current API excludes repeated indices and unequal
irreducible weights. Accepted nonzero roundoff detuning defines a PSD
approximation, not an exact equilibrium Jacobian. Underflow can make the
population/entropy coordinate map noninvertible in floating point.
No material event selection rules, absolute rates, grid convergence or
experimental boundary model have been validated.
