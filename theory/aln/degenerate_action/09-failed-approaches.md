# Failed approaches and limitations retained
Usage interruptions: several branches and final saves were halted and resumed. No interrupted execution is counted as completed evidence.
Compression-as-closure: disproved in a conserving positive-rate finite event model; equal initial block occupations still create hidden imbalance.
Squared-amplitude-as-phase-data: same squared entries can have different Gram spectra and transformed squares. Fixed-basis incoherent kinetics with supplied counting is NOT disproved.
Full-basis transport alone: a contraction consistency identity, not evidence of physical exact degeneracy or canonical channel normalization.
Clustering bug: the seed-distance algorithm can reuse a mode in overlapping groups on a three-frequency chain, yielding a nonunitary map and up to 1.5 squared-norm amplification in the adversarial example. The actual selected triplet has disjoint groups and is unaffected. The legacy script and R diagnostic remain preserved.
Fix: connected groups with diameter below tolerance only; ambiguous chains rejected, partitions compared across exports and block unitarity checked. Eight regressions and a material replay preserve original results.
Conserved-pole error masking: a small whole-resolvent relative error can hide a 25% relaxing-channel compression error in the finite example.
No approximation to short memory is accepted merely because the closure defect is small.

Portability check: the original repository-action checksum covered Windows CRLF bytes only. The portable memory experiment now accepts exactly that hash and the canonical Git LF hash, without relaxing source-content identity. Both checkout forms are tested; other versions remain outside the pinned comparison.
